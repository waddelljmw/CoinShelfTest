# Ideas for later updates

Nothing here is promised or scheduled. When you mention a new idea, I'll ask if it should go on this list. Each idea also gets a place in `PLAN.md` once you decide to build it.

1. **Album page view.** Keep the current album page as the default. Add a "View album" button that opens a virtual album where you turn pages, like a real Whitman or Dansco album.
2. **Report a problem button.** A small button in Options that opens a pre-filled note on your GitHub page, so problems reach me with the app version and what you were doing. Cheap to build; do it after the main features.
3. **First-time walkthrough.** A skippable tour for new users: how fast it is to add a coin step by step, how to view a coin, and cool features like adding an album and putting a coin in it.
4. **Shelf look on every page.** Make the other pages match the Home shelf, so it feels like real life. Keep a toggle between that and the current basic view (the basic view stays useful for long lists).
5. **Different flip sizes.** When adding a coin, "In a flip" defaults to 2x2, with other flip sizes as options.
6. **Inventory printout.** A printable copy of the whole collection, like the insurance report but made as a backup you can keep on paper. Decide later whether it sits with Import/Export and Backup in Options.
7. **Reorganize the main menu.** Rearrange the top-right dropdown so related pages sit together. Your rough layout to start from (wording must make sense to a non-technical person *and* a collector or dealer):
    - **My Cabinet** (today's Home shelf)
    - **My Coins**, with **My Albums** and **Storage** tucked under it
    - **Wants List**
    - **Coin Value**: the value dropdowns live here; the Insurance Report may move here
    - **My Stacks**
    - **PCGS Photograde**
    - Options stays last. Plan it on Opus; it only moves buttons, so it can be built on Sonnet after.
6. **Demo mode.** A built-in sample collection (lots of coins, rolls, 1 oz and 10 oz bars, a black box of wheat cents in 2x2 flips, partly filled albums) so a friend can try the app without seeing your real coins. Show off **photo fill** here (e.g. a ready-made example of a coin filled in from its photos), even while it's locked in the real app. Built from your backup plus made-up fill-in, kept separate from your real data. Best done once the features exist.
7. **Tablet layout.** Make the pages fit a tablet screen well.
8. **Coin ID numbers.** An easy numbering/lettering system giving every coin a unique ID you can write on its flip, then search the ID to see where it is. **Planned in PLAN.md Step 7.0** (type code + number, e.g. MD-012).
9. **Cabinet drawers on Home.** The sections below the shelf (melt by metal, recently added, recently sold) drawn as cabinet drawers you pull open. Builds on the collapsible sections from the Fix list. Goes with the shelf look (idea 4).
10. **Add many identical coins to a container at once.** Add a "How many?" count, pick the container once, then tap each coin's real spot on the container's grid (coins sit in a certain order in real life). Each saves as its own coin. Plan it on Opus after Step 4.4.
11. **AI test-user review.** Once the menu rework and demo mode exist, run one pretend first-time collector through the app (adding about 10 coins, trying each page). It writes an honest app-store-style review plus a note to you with: what was useful, what was confusing, what it wished for, how many taps tasks took, confusing words, anything that broke (with steps), what it thought of **photo fill** (or the locked "Coming soon" button), coins/albums it couldn't find (check against the Red Book, never guess), and a ranked wish list. Optionally a second run as a coin dealer to inform selling (Phase 7) and Seller Mode (Phase 8). Compare it with watching your friend's first 10 minutes. Keep it to one or two runs to save tokens.
12. **Free photo fill.** Use a free Google Gemini key in the photo-fill spot instead of a paid one (daily limits; check Google's terms on photo use first). Maybe also a free reader for slab labels.
